## Project handoff

This repo uses the model-neutral handoff system in `handoff-skill/handoff-skill/`.

- Before project work, read `handoff-skill/handoff-skill/README.md` and `handoff-skill/handoff-skill/handoff.md` completely. Treat the repository as the source of truth; if it conflicts with `handoff.md`, record the conflict and follow the verified state.
- Before ending substantive work, update `handoff-skill/handoff-skill/handoff.md` in place according to its README (no dated copies, absolute dates with timezone, unverified facts marked `Not confirmed`, no secrets or customer data).
- `read handoff` = read both files, verify current state, state the resume point, and continue.
- `write handoff` = inspect the session's work, update `handoff.md`, verify every required section, and report the saved path.
- Full prompts: `handoff-skill/handoff-skill/docs/PROMPTS.md`.
